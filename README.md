My project, **Fit Happens!**, applies the concepts from the notes by using HTML for structure and CSS for presentation. Each page follows the basic HTML document structure with `<!DOCTYPE html>`, `html`, `head`, `body`, metadata, page titles, and an external stylesheet. I used semantic elements such as `header`, `nav`, `main`, `section`, `article`, and `footer` to organize the content and improve accessibility. The header, navigation, main content, and footer also use the landmark roles `banner`, `navigation`, `main`, and `contentinfo`. Navigation links are grouped in unordered lists using `<ul>` and `<li>`, which provide list semantics natively. The project also applies heading hierarchy, internal and external links, unordered and ordered lists, images with descriptive `alt` text, and unique `id` attributes for links to specific page sections.

The workouts page uses embedded YouTube videos through `<iframe>` elements and organizes exercise information into tables. The tables include `<caption>` elements to describe their contents and `scope="col"` attributes to associate column headings with their data. The meals page uses articles, images, ingredient lists, and numbered preparation instructions. CSS concepts from the notes are demonstrated through an external stylesheet, classes, descendant selectors, flexbox layouts, colors, spacing, borders, and reusable styling across multiple pages. The project also uses link attributes such as `target="_blank"` and `rel="noopener noreferrer"` for external resources.
